# Employee Management App

A React-based employee management application with CRUD functionality,
Redux Toolkit state management, skeleton loaders, and responsive UI.

## Features
- View employees
- Add / edit employee details
- Delete employee with confirmation
- Skeleton loaders for better UX
- Responsive layout (mobile & desktop)

## Tech Stack
- React
- Redux Toolkit
- Bootstrap
- MockAPI

## Setup
```bash
npm install
npm run dev
